# ChessTrainer

**Couch to chess play. Never too late to start.**

A local-first chess learning app for beginners. It includes a staged curriculum, tactical puzzles, practice games, and saved progress.

## Run it

Open `index.html` in a modern browser. The chess rules library is loaded from a CDN, so an internet connection is currently needed for legal move handling and game analysis.

## What is included

- Eight lessons covering the rules, opening principles, special moves, and checkmate
- Five capture puzzles
- A slow practice game against a basic training opponent
- Browser-local progress and move history
- Post-game alternatives and short tactical lines

The review search is intentionally modest and is not a substitute for a full-strength chess engine. Its suggested lines are training clues, not proof of a forced win.
